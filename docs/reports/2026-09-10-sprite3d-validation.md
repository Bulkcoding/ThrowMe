# 3D 공 1.30.0 로컬 구현 검증

## 1.30.1 우클릭 연속 회전 수정

- 사용자 시험에서 긴 우클릭 드래그가 공 밖에서 멈추는 문제가 보고됐다. 기존 구면 투영은 같은 방향의 외부 좌표를 동일한 점으로 제한했다.
- 직전 입력과 현재 입력의 차이를 회전축과 각도로 변환하도록 변경했다. 반지름 단위 이동 1을 1라디안으로 환산하며, 공 밖에서도 동일한 감도로 회전한다.
- 상하좌우·대각선 5방향에서 반지름 20배까지 연속 드래그, 입력 이벤트 분할 차이, 긴 드래그 후 관성 방향, 왕복 복원과 비정상 좌표 검사를 추가했다. 기존 검사 포함 2,235개 동작·이미지 검사 통과, Release 빌드 경고 0·오류 0.
- 실제 물리 마우스 조작은 이번에도 자동 검증하지 않았다. 사용자 재시험용 단일 실행 파일은 dist/ThrowMe-1.30.1-local-singlefile/ThrowMe.exe에 게시한다.

- 날짜: 2026-09-10. 기준 커밋 b484529(1.29.0). 최종 git fetch 후 origin/main과 기준 커밋 일치 확인.
- 승인된 변경 설계에 따라 실시간 WPF 3D를 구현했다. Blender 시트 방식은 인터뷰에서 제외됐다. 별도 카드, 민트 기본 모델, 다축 회전과 관성, 정면 사용자 이미지, 6단계 충돌과 200ms 복구, 자동 이동 도약, 방 자세 전달을 연결했다.
- 버전: 1.30.0 / AssemblyVersion·FileVersion 1.30.0.0. 새 외부 의존성 없음. 푸시·릴리스·운영 방 접속 없음.

## 계획과 달라진 구현 세부

- 창 밖에서 마우스가 해제되는 경우를 처리하기 위해 우클릭 후보 시작부터 마우스를 캡처한다. 실제 회전은 이동 문턱을 넘은 후 시작한다.
- 검증용 내부 생성자와 AppPaths.DirOverride를 추가했다. 일반 앱 시작은 기존 외부 연동을 유지하며 하네스만 외부 연동을 끈다.

## 미검증과 전달 범위

- 컴퓨터 조작 도구의 native pipe 연결이 두 차례 실패하여 실제 우클릭·드래그·짧은 클릭 메뉴·창 밖 해제·캡처 상실 상호작용을 시험하지 못했다. 코드 검토와 상태 하네스 통과를 실제 입력 통과로 해석하지 않는다.
- 실제 혼합 DPI 다중 모니터 이동과 운영 환경의 다중 PC 왕복은 미검증이다. PNG 출력 배율 및 로컬 통신 하네스는 이 시험을 대신하지 않는다.
- 따라서 구현과 로컬 자동 검증은 마쳤지만 전체 수용 기준 충족이나 배포 준비 완료를 주장하지 않는다. 실제 입력과 혼합 DPI 환경 검증이 남아 있다.
