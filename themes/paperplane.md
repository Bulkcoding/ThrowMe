# 테마: 종이비행기 (`paperplane`)

> 이 파일은 이 테마 세션이 **작업하면서 직접 갱신**한다.
> 평소 자동으로 읽지 않고, **사용자가 요청할 때만** 읽는 문서다.

- **브랜치 / 폴더**: `theme/paperplane` / `../ThrowMe-paperplane`
- **enum**: `SlimeSkinKind.PaperPlane = 7` (예약표 배정 번호)
- **설정창 표시 이름**: `"종이비행기"`
- **상태**: ⬜ 진행 중

---

## 1. 컨셉 / 디자인
- 접힌 자국(fold line)이 보이는 종이비행기. 면마다 명암을 달리해 접힌 입체감을 낸다.
- **단단한 공이 아니라 "날아가는 물체"** 라는 점이 기존 테마와 가장 다르다.
  `Rigid`(찌그러짐 없음)로 두고, 진행 방향으로 **기수(nose)가 향하도록 회전**한다
  (구르는 회전 `SpinAngle` 이 아니라 `atan2(vy, vx)`).

### 1.1 확정된 동작 규칙 (사용자 결정)

| # | 항목 | 결정 |
|:--:|------|------|
| 1 | **활공(glide)** | 그냥 떨어지지 않고 **양력을 받아 미끄러지듯** 나아간다 |
| 2 | **중력** | **농구공과 동일하게 중력의 영향**을 받는다 |
| 3 | **벽 충돌** | 튕기지 않고 **구겨지면서 떨어진다.** 바닥에 다 떨어지면 **원상복구** |
| 4 | **좌우 흔들림** | 활공 중 살짝 흔들리게(sway) — 종이비행기 느낌의 핵심 |
| 5 | **마우스 바람** | 활공 중 커서를 가져다 대면 **상하좌우 방향대로 바람을 부는 것처럼** 밀려난다. 바람 애니메이션 표시 |
| 6 | **바람 단축키 (기본 `Ctrl + Space`)** | 활공 중 누르면 **비행기 아래로 바람을 쏴서** 더 오래 활공. **`Ctrl` 은 고정(변경 불가)** + 사용자가 지정하는 키 1개(기본 `Space`) |

#### 구현 힌트 (기존 코드 재사용)
- **중력**: `SlimePhysicsEngine.GravityY` 가 이미 있다. `UpdateSkinBehavior()` 에서
  농구공이 `BasketballGravity(2200)` 를 넣는 것과 같은 방식으로 종이비행기 값을 넣으면 된다.
  종이는 가벼우니 농구공보다 **작은 중력**이 어울린다(느리게 가라앉는 느낌).
- **양력**: 중력을 그대로 두고, 속도 방향에 수직인 위쪽 성분으로 가속을 더하면
  "떨어지면서도 앞으로 미끄러지는" 활공이 된다. 속도가 빠를수록 양력이 커지게 하면 자연스럽다.
  (속도가 죽으면 양력도 죽어 스르륵 떨어짐 → 종이비행기다움)
- **구겨짐**: 충돌 시 스킨을 구겨진 모양으로 바꾸고(`ISkinClickEffect` 처럼 상태 전환 메서드 추가),
  양력을 끄고 중력만 받게 하면 종이 뭉치처럼 떨어진다. 바닥(작업 영역 하단) 도달 시 원래 모양 복구.
- **바람 애니메이션**: 파티클/오버레이 창이 이미 있다(`ParticleOverlayWindow` 패턴 참고 —
  작은 창을 대상 위치로 **이동만** 시키는 저비용 방식).

### 바람 단축키 규격 (확정) — 반드시 이대로

잡기·숨기기 단축키는 `RegisterHotKey` 로 **전역 등록**된다.
Space 를 그냥 전역 등록하면 **다른 모든 앱에서 스페이스바가 먹통**이 되므로
(문서 입력·브라우저 스크롤·게임 등) 아래 두 가지를 **함께** 적용한다.

**① `Ctrl` 고정 + 사용자 지정 키 1개**
- 수정자는 **항상 `Ctrl`** 이며 **사용자가 바꿀 수 없다.** 설정창에서 `Ctrl` 은
  비활성(회색) 상태로 보여 주고, 사용자는 **뒤에 붙는 키 1개만** 지정한다.
- 기본값은 `Space` → 표시는 **`Ctrl + Space`**.
- 즉 저장 대상은 "키 하나"뿐이다(수정자는 상수 `Ctrl`). 기존 `CatchHotkeyMod/Vk` 처럼
  수정자까지 저장하는 형식이 아니라, **`WindHotkeyVk` 하나만** 두면 된다.

**② 활공 중에만 등록**
- 종이비행기 스킨 + **공중에 떠 있는 동안에만** `RegisterHotKey`
- 착지 · 스킨 변경 · 숨김(`SlimeVisible=false`) · 종료 시 **즉시 `UnregisterHotKey`**

두 가지를 같이 적용해야 안전하다. `Ctrl` 조합이라 충돌 위험이 이미 낮고,
활공 중에만 잡으므로 평소에는 그 조합조차 다른 앱이 그대로 쓴다.

## 2. 만든 / 수정한 파일
**신규**
- `src/ThrowMe/Views/Skins/PaperPlaneSkin.xaml`
- `src/ThrowMe/Views/Skins/PaperPlaneSkin.xaml.cs`

**공유 파일 append (충돌 핫스팟 — 기존 줄 수정 금지, 맨 끝에 한 줄만 추가)**
- `Models/SlimeSkinKind.cs` — enum `PaperPlane = 7` 추가
- `Views/SlimeWindow.xaml.cs` → `ApplySkin()` 에 `SlimeSkinKind.PaperPlane => new PaperPlaneSkin()` case 추가
- `Views/SettingsWindow.xaml.cs` → `Skins[]` 에 `(PaperPlane, "종이비행기")`, `MakeSkin()` 에 case 추가

**이 테마에서 추가로 건드릴 곳 (위 4곳 외)**
- `Models/AppSettings.cs` — 바람 단축키 **키 하나만**(`WindHotkeyVk`, 기본 `Space`=0x20) 추가.
  수정자는 `Ctrl` 고정이라 저장하지 않는다.
- `Views/SlimeWindow.xaml.cs` — 활공/양력·구겨짐·sway·마우스 바람·단축키 등록/해제 로직.
  `UpdateSkinBehavior()` 에서 `GravityY` 설정(농구공과 같은 자리).
- `Views/SettingsWindow.xaml.cs` — 단축키 재설정 UI(기존 잡기/숨기기 단축키 행과 같은 형식).
  단, **`Ctrl` 은 고정 표시(비활성)** 하고 뒤 키 1개만 캡처받는다.
- **바람 오버레이 창을 새로 만든다면** → 규칙 §3.6 에 따라 `ApplyVisibility()` 에 반드시 등록할 것
  (숨기기 단축키로 바람 이펙트까지 같이 사라져야 한다).

## 4. 검증
- [ ] 빌드 0 경고 / 0 오류
- [ ] 설정창 테마 칩에 표시되고 선택 시 즉시 교체됨
- [ ] 드래그·던지기·충돌 정상 (활공/회전이 의도대로)
- [ ] 유휴 시 CPU ≈ 0
- [ ] **숨기기 단축키 → 이 테마가 띄운 것까지 전부 사라짐** (규칙 §3.6)
- [ ] **다시 보이기 → 숨기기 직전 상태 그대로 복원**

### 4.1 이 테마 전용 검증 (확정 규칙 6가지)
- [ ] **활공**: 던지면 바로 떨어지지 않고 앞으로 미끄러지듯 나아간다. 속도가 죽으면 스르륵 가라앉는다
- [ ] **중력**: 가만히 두면 아래로 가라앉는다(농구공처럼). 종이답게 농구공보다 느리게
- [ ] **구겨짐**: 벽에 부딪히면 튕기지 않고 구겨진 모양으로 바뀌어 떨어진다
- [ ] **복구**: 바닥에 다 떨어지면 원래 종이비행기 모양으로 되돌아온다
- [ ] **흔들림**: 활공 중 좌우로 살짝 흔들린다(과하지 않게)
- [ ] **마우스 바람**: 활공 중 커서를 대면 커서 방향(상하좌우)대로 밀려나고 바람 애니메이션이 보인다
- [ ] **단축키 바람**: 활공 중 `Ctrl + Space` → 아래로 바람, 체공이 눈에 띄게 길어진다
- [ ] **설정창에서 `Ctrl` 은 고정(변경 불가)** 으로 보이고, 뒤 키만 다른 키로 바꿀 수 있다
- [ ] 바꾼 키로도 정상 동작한다 (예: `Ctrl + W`)
- [ ] ⚠ **활공 중이 아닐 때는 그 조합을 앱이 가로채지 않는다** — 착지·다른 스킨·숨김 상태에서
      메모장/브라우저에 `Ctrl + Space` 를 눌러 평소대로 동작하는지 직접 확인할 것
